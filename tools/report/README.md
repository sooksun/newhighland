# รายงานผลการประเมินโรงเรียนพื้นที่ลักษณะพิเศษ (HTML ฉบับเต็ม)

สร้างรายงานผลการประเมิน **ทั้งกลุ่มพื้นที่สูงและกลุ่มพื้นที่เกาะ ทุกมิติ** เป็นไฟล์ HTML เดี่ยว
กราฟทุกชิ้นเป็น **inline SVG ที่วาดด้วย PHP** — ไม่มี CDN, ไม่มี JS library ภายนอก จึงเปิดดูแบบ
ออฟไลน์ได้ ส่งต่อทางอีเมลได้ และสั่งพิมพ์เป็น PDF จากเบราว์เซอร์ได้ทันที (ปุ่ม "พิมพ์ / บันทึก PDF")

## วิธีสร้างรายงาน

### 1) ผ่านหน้าเว็บ (ใช้ได้บน production ที่เข้า CLI ไม่ได้)

ล็อกอินระดับ **สพฐ. (admin)** → เมนู **รายงานสถิติ** → ปุ่ม **"รายงานฉบับเต็ม (HTML)"**

| เส้นทาง | ผลลัพธ์ |
|---|---|
| `report/full` | แสดงรายงานในเบราว์เซอร์ |
| `report/full?download=1` | ดาวน์โหลดเป็นไฟล์ `.html` |
| `report/full?year=2569` | เจาะจงปีงบประมาณ |
| `report/full?year=all` | รวมทุกปีงบประมาณที่มีข้อมูล |

### 2) ผ่าน command line

```bash
php tools/report/generate_report.php                       # ปีที่มีข้อมูลมากที่สุด (auto)
php tools/report/generate_report.php --year=2569           # เจาะจงปีงบประมาณ
php tools/report/generate_report.php --year=all            # รวมทุกปี
php tools/report/generate_report.php --out=storage/reports/x.html
php tools/report/generate_report.php --config=config/server/config.php
```

ผลลัพธ์เริ่มต้นอยู่ที่ `storage/reports/report_special_area_<ปี>.html`
สคริปต์เลือกไฟล์ config ตามลำดับ: `--config` → `config/server/config.php` → `config/config.php`
จึงอ่านฐานข้อมูลของเครื่องที่รันเสมอ (บน production = ข้อมูล production)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `generate_report.php` | ตัวห่อฝั่ง CLI — อ่าน argument, ต่อฐานข้อมูล, เขียนไฟล์ |
| `build.php` | `buildReport()` — ประกอบบริบทรายงานทั้งหมดแล้วคืน HTML (ใช้ร่วมกันทั้ง CLI และเว็บ) |
| `lib.php` | ป้ายชื่อตัวชี้วัด/ระดับ/ภูมิภาค + สถิติพื้นฐาน (describe, percentile, Pearson) + ตัวช่วยจัดรูปแบบ |
| `data.php` | ดึงแถวจาก `highland_eval` / `island_eval` / `highland_eval_hilltrib` / `school_confirm` แล้ววิเคราะห์ทุกมิติ |
| `charts.php` | กราฟ SVG: แท่งตั้ง/นอน, โดนัท, แท่งซ้อน, สองทาง (สหสัมพันธ์), เส้น, กระจาย, กล่อง |
| `render.php` | ส่วนวิเคราะห์รายกลุ่มพื้นที่ (ใช้โครงเดียวกันทั้งพื้นที่สูงและพื้นที่เกาะ) |
| `page.php` | โครงหน้าเต็ม + CSS + JS (ค้นหา/กรอง/เรียงตาราง) + บทสรุปผู้บริหาร/เปรียบเทียบ/ภาคผนวก |

## หัวข้อในรายงาน

1. บทสรุปผู้บริหาร (KPI + คำบรรยายที่คำนวณจากข้อมูลจริง)
2. เปรียบเทียบกลุ่มพื้นที่สูงกับกลุ่มพื้นที่เกาะ
3. การรับรองการคงอยู่ (`school_confirm` ปีงบประมาณตาม `acad_year`)
4./5. ผลการประเมินรายกลุ่มพื้นที่ — การกระจายคะแนน · ระดับความยุ่งยาก · คะแนนรายข้อ ·
   การกระจายคำตอบ · สาธารณูปโภค · ภูมิภาค/จังหวัด/เขตพื้นที่ · ขนาดโรงเรียน ·
   สถิติเชิงพรรณนา · สหสัมพันธ์ · ค่าเฉลี่ยตามระดับ · แผนภาพการกระจาย ·
   กลุ่มชาติพันธุ์ (เฉพาะพื้นที่สูง) · อันดับสูงสุด-ต่ำสุด · สถานะการรับรอง
6. แนวโน้มรายปีงบประมาณ (ทุกปีที่มีข้อมูล)
7. คุณภาพและความครบถ้วนของข้อมูล
8. ภาคผนวก — ตารางรายโรงเรียน ค้นหา/กรอง/เรียงลำดับได้
9. ระเบียบวิธีและนิยาม

## นิยามที่ใช้ (ตรงกับตรรกะของระบบ)

- **ประเมินแล้ว** = `sum_score > 0` เท่านั้น
- **ผ่านเกณฑ์** = `sum_score >= 50`
- **ระดับความยุ่งยาก** 50–59 = กลุ่ม 1, 60–69 = กลุ่ม 2, 70+ = กลุ่ม 3
  (ตรงกับ `App\Services\ScoreService` และ `IslandScoreService`)
- **ขนาดโรงเรียน** เล็ก ≤ 120 · กลาง 121–300 · ใหญ่ 301–499 · ใหญ่พิเศษ ≥ 500 คน
- ข้อ 7–10 ของพื้นที่สูงเลือกได้หลายคำตอบ — รายงานใช้ "ระดับสูงสุดที่เลือก" เช่นเดียวกับสูตรคะแนน

## หมายเหตุ

- SD ใช้สูตรกลุ่มตัวอย่าง (ddof = 1) และควอไทล์แบบ linear interpolation — ตรงกับ pandas/NumPy
- ค่าสหสัมพันธ์ตรวจสอบแล้วกับค่าอ้างอิงใน `App\Services\StatService`
  (พื้นที่สูง 2565: r ระหว่างความสูงกับคะแนนรวม = 0.665)
- โฟลเดอร์ `tools/` ถูกปิดกั้นจากเว็บด้วย `.htaccess` และ `generate_report.php` ปฏิเสธการเรียกที่ไม่ใช่ CLI
